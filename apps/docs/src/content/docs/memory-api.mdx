---
title: Memory API
description: HTTP endpoints for creating, listing, retrieving, and searching memories.
---

The API worker is a Hono service in `apps/api`. It exposes JSON endpoints under
`/v1/memories`.

## Endpoints

- `GET /health`
- `GET /v1/memories?organizationId=...&namespace=...`
- `POST /v1/memories`
- `GET /v1/memories/:id`
- `POST /v1/memories/search`

## Search behavior

`POST /v1/memories/search` uses Vectorize when `queryEmbedding` is provided.
When omitted, it falls back to recent D1 rows for the organization and namespace.

```json
{
  "organizationId": "org_demo",
  "namespace": "support",
  "queryEmbedding": [0.012, 0.034, 0.056],
  "limit": 10
}
```
