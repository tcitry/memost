## 安装与构建

在 monorepo 根目录：

```bash
pnpm --filter cli build
pnpm link --global --dir apps/cli   # 可选：全局 memost
# 或
pnpm --filter cli dev -- login
```

本地配置写入 `~/.memost/config.json`（权限 `600`）。

## 快速开始

```bash
# 1. 配置 API 与 Dashboard 地址（本地开发默认值通常已够用）
memost config set api-url http://127.0.0.1:8787
memost config set web-url http://localhost:3000

# 2. Clerk 登录（会打开浏览器 /cli/login，把 JWT 回传给 CLI）
memost login

# 3. 创建 Agent（自动保存 defaultAgentId 与 apiKey）
memost agents create -n "dev-agent"

# 4. 写入与检索记忆
memost memories add -c "用户偏好暗色主题"
memost memories search -q "主题"
```

仅使用 API Key（无需 Clerk 管理界面时）：

```bash
memost login --api-key mst_test_xxxx
memost memories add -c "hello" -a agent_xxx
```

## 全局命令

| 命令 | 说明 |
|------|------|
| `memost login` | 浏览器 Clerk 登录 |
| `memost login --token <jwt>` | 手动粘贴 JWT |
| `memost login --api-key <mst_*>` | 仅保存记忆 API Key |
| `memost logout` | 清除 Clerk 会话 |
| `memost whoami` | 配置摘要 + `/health` + agents 探测 |
| `memost config show` | 显示配置（脱敏） |
| `memost config set api-url <url>` | API Worker 地址 |
| `memost config set web-url <url>` | Dashboard 地址（login 用） |

## agents

组织记忆的最大单位是 **Agent**，其下按 **pid**（process / project）与 **tid**（thread，可选）分层。

| 命令 | 说明 |
|------|------|
| `memost agents list` | 列出 Agent |
| `memost agents create -n <name>` | 创建 Agent（返回一次性 API Key） |
| `memost agents get <id>` | 查看详情 |
| `memost agents delete <id>` | 删除 Agent |
| `memost agents use <id>` | 设为默认 Agent |

选项：`--description`、`--default-pid`、`--json`。

## keys

需 Clerk 登录；用于管理 `mst_*` 凭证。

| 命令 | 说明 |
|------|------|
| `memost keys list -a <agentId>` | 列出 Key |
| `memost keys create -a <agentId>` | 创建 Key |
| `memost keys revoke -a <agentId> <keyId>` | 吊销 |
| `memost keys use <raw>` | 将 raw key 写入配置 |

## memories

可用 **API Key** 或 **Clerk + x-agent-id** 调用 `/v1/memories`。

| 命令 | 说明 |
|------|------|
| `memost memories add -c <text>` | 写入记忆 |
| `memost memories search -q <query>` | 语义检索 |
| `memost memories list` | 列出记忆 |

选项：`--agent`、`--pid`、`--tid`、`--no-kg`、`--json`。

## 记忆层级

```text
owner (Clerk user / org)
 └── agent_id          # 最大隔离单位
      └── pid          # process / project
           └── tid?    # thread / 会话（可选）
```

与 D1 表 `agents`、`memories.pid`、`memories.tid`、`kg_triples` 字段一致。
