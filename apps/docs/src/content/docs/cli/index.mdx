The memo.st CLI lives in `apps/cli` and publishes the `memost` executable from
the compiled `dist/index.js` entrypoint.

The CLI supports **Clerk browser login** (`memost login`), **Agent / API key
management**, and **memory add / search / list** against the API worker. Local
auth is stored in `~/.memost/auth.json` and general config in
`~/.memost/config.json`. See [CLI commands](/docs/cli/commands) for the full
reference.

Memory scope hierarchy: **Agent** → **pid** (process) → **tid** (thread,
optional), matching the D1 schema and dashboard.

## Package

```json
{
  "name": "cli",
  "bin": {
    "memost": "./dist/index.js"
  }
}
```

## Requirements

The repository targets Node.js 20 or newer.

```bash
node --version
pnpm --version
```

## Local usage

Run the source entrypoint during development:

```bash
pnpm --filter cli dev --help
```

Build and run the compiled output:

```bash
pnpm --filter cli build
node apps/cli/dist/index.js --help
```
